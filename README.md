# Number Guessing Game

-- A web-based number guessing game built with Python and Flask. The application generates a random number, and the player must guess it within a limited number of attempts. Guess correctly to win; run out of attempts and it's Game Over.
-- Features

    Configurable guess limit – Set the number of allowed guesses (default: 5).

    Configurable number range – Set the minimum and maximum values for the secret number (default: 10 to 100).

    Maximum guess cap – Prevents players from exceeding the configured guess limit.

    Graceful invalid input handling – Invalid entries do not penalize the player.

    Game state tracking – Uses Flask cookies to persist progress.

    Restart option – Allows players to start a new game at any time.

-- Technologies Used

    Python 3

    Flask

    HTML

    CSS
